Initial commit: E-commerce Storefront and Admin Foundation

Features implemented:
- Next.js 14 App Router setup with TypeScript and Tailwind CSS.
- Prisma and MariaDB setup with full schema for Products, Orders, Categories, Settings.
- Authentication implemented using NextAuth v5 (credentials provider with bcrypt).
- File upload integration using Cloudinary Node SDK.
- Complete storefront UI including Homepage, Category pages, Product detail, Cart, and Checkout.
- Interactive shopping cart with local storage persistence and Context.
- Admin dashboard layout and CRUD screens for Products, Categories, and Orders.
- Database seeded with initial mockup data connected natively.
- Dynamic site settings for global configurations and analytics (GA/Pixel) integration.
